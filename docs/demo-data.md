# 固定离线演示数据

离线数据实现位于 `src/api/mockData.js`，所有响应都标记 `source: sample-snapshot`。`npm run demo` 会在子进程环境中强制 `VITE_DATA_MODE=mock`、清空浏览器 AK，因此不会被本机 `.env.local` 或网络状态改变。

## 快照元数据

| 字段 | 值 |
| --- | --- |
| 默认中心 | `116.284206, 40.051819` BD-09 |
| 地址标签 | 北京市海淀区中关村软件园 |
| 采集时间标记 | `2026-09-10T09:00:00+08:00` |
| 数据来源 | 为演示编制的固定样例，不是真实百度地图快照 |
| POI | 18 条，覆盖 8 类民生设施 |
| 灰区 | 3 个 |
| 网格 | 113 个，其中盲点 32 个 |
| 必测覆盖率 | 菜市场 81%，药店 86%，小学 72% |
| 边界复核 | 12 / 12 样例点达标 |

固定数据用于演示交互、数据契约、评分和导出，不能用来声称真实社区达标。真实调用的结果与限制见 [真实社区报告](real-community-report.md)。

## 可重复检查

```bash
npm ci
npm run check:submission
npm run demo
```

`check:submission` 会执行样例契约检查，确认 18 条 POI、3 个灰区、三个必测类别和固定时间戳，并输出 `mockData.js` 的 SHA-256。
